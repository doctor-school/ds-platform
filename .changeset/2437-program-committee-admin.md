046 programme committee in the admin (#2437): a committee member's admin is the «Заявки» registry of each bound event — filters by kind, status, sent dates and submitter, title/author search, server-side sort — with the submission card in a side panel and the «Решение» block (allowed transitions only, a comment required for «Отклонена» and «На доработке»); the platform administrator sees «Заявки» and «Настройки приёма» per event and alone can extend a revision deadline in the card. Status and kind labels come from `@ds/congress-submissions`, the author cabinet's source.
