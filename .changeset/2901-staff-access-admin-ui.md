Staff access (047 EARS-1…EARS-6, EARS-8): a platform administrator gets the «Доступы» section — the list of everyone with admin access (ФИО, почта, роль, мероприятие) with search and paging, and «Выдать доступ»: email, ФИО, role and, for a congress role, the event. A new account gets a temporary password shown once with «Скопировать»; an existing account gets the role added; every refusal shows at the form with the input kept. When the operator's second factor is older than the step-up window, the grant opens the existing code screen in re-verify mode and, after the code, returns to «Доступы» and sends the grant again with the entered values. Congress registrars and the programme committee do not see the section.
