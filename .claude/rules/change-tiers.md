# Change tiers (reference)

Procedure is proportional to risk (Ship / Show / Ask). Pick the tier before work starts, by what the change does; the changed-file set sets a mechanical minimum the author may never go below. When unsure → the higher tier. An owner request that turns out to need new logic is re-tiered, and the owner told, before work starts.

| Tier | Qualifies                                                                                                                                                                                                                             | Procedure                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ship | copy; substituting already-existing data into an existing component (a dynamic value instead of a hardcode); a small presentational tweak — only ship paths (below), no new/removed/renamed non-test file, ≤80 changed non-test lines | the lead authors inline (no brief, no implementer); worktree + branch as usual; no separate Issue required (`Closes #N` when an owner Issue exists, else `Refs #<epic>`); tests (the only exception to «no production code without a failing test»): none pinning wording, exactly one for a value substitution, existing tests quoting old text updated; green CI; Stage-B = the owner's chat decision (below); no Mode (a); no ui-parity evidence; land with `pnpm pr:land <N>` |
| Show | a new state/behaviour inside an existing feature; no Ask path                                                                                                                                                                         | normal dispatch; one Mode (a) review; ui-parity evidence as for every UI PR, captured from the agent's local run; Stage-B GO on those PR captures, no staging slot                                                                                                                                                                                                                                                                                                                |
| Ask  | auth, DB/migrations, API contracts/schemas, new forms with a data model, security, infra/deploy, CI/guards/tooling, dependencies, specs/ADRs                                                                                          | the full procedure in `repo-conventions.md` and the skills (per-PR staging slot for Stage-B, …)                                                                                                                                                                                                                                                                                                                                                                                   |

**Declaration.** Exactly one PR-body line `Change-tier: ship|show|ask — <reason>`. Absent, duplicated, malformed, or a ship/show line without a real reason (`n/a`, `none`, `tbd`, a `<placeholder>`) = `ask`.

**Mechanical minimum** (`tools/lint/lib/change-tier.ts`, one rule for every gate). `ask` when any changed path (or a rename source) is under `packages/{db,schemas,api-client}/`, `apps/api/`, `infra/` `tools/` `.github/` `.claude/` `.codex/` `scripts/`, any `design-source/`, `apps/docs/content/{specs,adr,skills}/`, or is `AGENTS.md`/`CLAUDE.md`, a `package.json`, the lockfile/workspace/`turbo.json`, a `*.config.*`, `Dockerfile*`, `docker-compose*`, `.env*`, `middleware.*`, `proxy.*`, `apps/docs/content/agent-discipline.md` or a `migrations/` file — except the email-copy allowlist `apps/api/src/mailer/code-emails.ts`, `apps/api/src/mailer/notice-emails.ts`, `apps/api/test/support/notification-subjects.ts`; also `ask` when the changed-file set is empty or incomplete. Otherwise `show` when a non-test file is added/removed/renamed, is not a ship path, a test or `.changeset/*.md` file is removed/renamed, or non-test non-changeset files exceed 80 changed lines. Otherwise `ship`.

**Ship paths** (an allowlist; tests are exempt): render-capable UI source per `isUiSourcePath` (`tools/lint/lib/ui-surface.ts`); a copy module `packages/*/src/**/{copy.ts,*-copy.ts,copy/**}`; the email-copy allowlist above; `.changeset/*.md`; plain product docs `apps/docs/content/**/*.md(x)` outside `specs/`, `adr/`, `skills/` and `agent-discipline.md`. UI- or copy-shaped files carrying server, routing or auth behaviour are never ship paths: a `server/` or `actions/` segment, an `*action*` source, a Next.js `app/**/{page,layout,route,template,default,loading,error,not-found,global-error}` file, `lib/**auth*`, any `auth` path segment outside `src/ui/` or a copy module, `proxy.*`, `middleware.*`, `instrumentation.*`. Everything else (models, `lib/`, hooks, routing helpers) is at least `show`.

**Enforcement.** The `change-tier` guard (BLOCK, `pr-body-guards.yml`, also in `pnpm pr:preflight`) refuses a declaration below the minimum. Merge gate: a body declaring ship is re-proven on the REST file listing, bound to the merge head (`headRefOid` read before and after the listing must equal it); verified, it prints `Mode (a) not required — Change-tier ship verified (…)`; not verified, it prints why and requires the head-pinned Mode (a) APPROVE. `ui-parity` skips a verified ship PR. `.github/ui-evidence/**` captures are exempt from the minimum, like tests. `stage-b` routes on the runtime files only — tests, `.changeset/*.md`, `.github/ui-evidence/**`, `apps/docs/content/**` docs and `.feature` files excluded — so a declaration those files forced up routes by the runtime minimum (one declared above the whole-PR minimum stands): a ship GO needs no live URL; a show GO may cite `Stage-B-evidence: https://…` (a PR capture) in place of `Stage-B-live-url`. Every GO keeps the `Stage-B-head` pin with recorded-at, owner-quote and source; a new head carries it when it is a pure rebase or when the PR's own delta since the recorded head (net of main) is only those non-runtime files — the guard prints the carried files; a runtime file needs a fresh verdict. `N/A (no visual surface) — lead-certified` on a PR without environment-sensitive paths (auth: an `auth` segment, `lib/**auth*`, `app/**/{login,register,verify,reset,mfa}/`, `middleware.*`, `proxy.*`; `apps/api/drizzle/`, `packages/db/src/schema/`, `infra/`, `apps/api/src/mailer/`, `apps/api/src/bot-protection/`, any `idp`/`zitadel`/`captcha` path) needs no slot: a green CI e2e check on the head plus main-vs-head captures of every touched screen as `Stage-B-evidence: https://…`; an environment-sensitive PR keeps the live slot report. An owner quote found verbatim in `AGENTS.md`, `CLAUDE.md`, `.claude/rules/**`, `agent-discipline.md` or `skills/**` is refused: an instruction line is not an owner decision. Both guards treat a PR whose changed-files count is missing or does not match the listing as `ask`.
