# 013 — Статичная публичная главная Академии

## Скоуп

Этот срез публикует точное слитое демо Академии на публичном /. Страница
статична. Поля формы партнёрства и кнопка отправки остаются отключёнными, явно
сообщают, что данные не отправляются, и не имеют endpoint. Рабочая форма
отслеживается отдельно.

## EARS-требования

- **EARS-1** _(realizes: US-1, US-5)_ — Когда посетитель запрашивает публичный
  /, портал должен отрисовать статичную главную Академии с точным порядком
  секций, текстами, ассетами и адаптивной композицией из PRD, без редиректа и
  без чтения CMS или API.
- **EARS-2** _(realizes: US-2, US-3, US-5)_ — Страница должна показать ровно
  шесть переданных портретов, одни и те же две утверждённые строки в блоках
  «Проект» и «Эфиры», точную B2B-ссылку Rutube, точную ссылку на политику и
  никаких выдуманных метрик проектов.
- **EARS-3** _(realizes: US-4)_ — Пока follow-up рабочей формы не доставлен,
  fieldset и кнопка отправки превью партнёрства должны оставаться отключёнными,
  показывать «Демо: данные не отправляются», не отправлять сетевой запрос и не
  сохранять значения.
- **EARS-4** _(realizes: US-1, US-3, US-5)_ — Статичная страница должна
  сохранять утверждённое поведение демо на desktop и mobile в светлой и тёмной
  темах, быть читаемой с клавиатуры и проходить Academy Playwright и axe.

## Верификация

| Требование | Доказательство                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| EARS-1     | Браузерный тест production-маршрута проверяет HTTP 200, порядок секций, ключевые тексты и отсутствие динамического fetch. |
| EARS-2     | Браузерный тест проверяет шесть портретов и обе точные внешние цели в обоих повторяющихся блоках.                         |
| EARS-3     | Браузерный тест проверяет disabled fieldset/кнопку, видимую надпись и отсутствие запросов формы.                          |
| EARS-4     | Playwright покрывает desktop/mobile и light/dark; axe не находит serious или critical нарушений.                          |

## Явные исключения

Рабочая форма, JSON-сохранение, API, база данных, CMS, очередь, уведомления,
аналитика и админка не входят в этот релиз.
