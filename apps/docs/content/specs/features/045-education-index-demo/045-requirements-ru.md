# 045 — Образовательный индекс · демо (Требования)

## Результат

Потенциальный партнёр (фарма/медтех) видит на проде демо публичного лидерборда «Образовательный индекс» и демонстрационный кабинет партнёра на вымышленных данных — до того, как появятся фичи 032 (лидерборд инвесторов) и 035 (кабинет инвестора).

## Область

**Входит:**

- Два публичных маршрута без входа в `apps/portal`: `/education-index` (публичный лидерборд) и `/education-index/partner-demo` (кабинет, организация «Ортелла Биотех»).
- Детерминированные фикстуры, воспроизводящие набор данных промпта 23 (12 вымышленных организаций, недельная серия индекса, метрики кабинета).
- Статичные полосы/шкалы/плашки из токенов `@ds/design-system` (без чарт-библиотеки, примитива графика в дизайн-системе нет).
- Временность: обе страницы удаляются в релизе, который выводит 032 и 035.

**Не входит:**

- Вход, любое обращение к API/БД, реальные аккаунты партнёров, реальные логотипы.
- Сами фичи 032, 035, 036.
- Загрузка, ошибка и пустые состояния (демо полностью статично).
- Цена за контакт/врача в интерфейсе.

## Ограничения

- Комплаенс (REQ-D5, кодекс EAPM): ни на одной странице — пациенты, спасённые жизни, помощь родственникам, связь с продажами, торговые названия препаратов; только язык «осведомлённость» / «образование», никогда более сильное медицинское утверждение.
- Словарь (F-1 / REQ-D6): организация — «партнёр» / «инвестор», никогда «спонсор», «рекламодатель», «вкладчик».
- Слово «майнинг» / «намайнено» никогда не появляется на публичном экране (решение владельца, #2360).
- Только вымышленные данные (REQ-D8): названия организаций и сгенерированные SVG-эмблемы вымышлены; ни одна реальная организация или человек не достижимы через данные фикстур.

## Модель событий

Тривиальная — команд и событий нет, записи нет. Модель чтения — статичный модуль фикстур (`apps/portal`), возвращающий набор из 12 организаций и недельную серию; обе страницы рендерятся синхронно из него. Обращений к API и БД нет.

## Требования EARS

- **EARS-1** — СИСТЕМА ДОЛЖНА отдавать `/education-index` и `/education-index/partner-demo` в `apps/portal` как публичные маршруты, доступные без аутентификации и без проверки сессии.
- **EARS-2** — СИСТЕМА ДОЛЖНА рендерить публичный лидерборд из статичного модуля фикстур ровно с 12 организациями промпта 23, без обращений к сети, API или БД.
- **EARS-3** — СИСТЕМА ДОЛЖНА показывать по каждой организации составной индекс (среднее доли инвестиций и доли внимания врачей, пересчитанное к лидеру недели как 100), недельную дельту мест, сумму и долю инвестиций (REQ-D2, REQ-D7), число обученных врачей, созданных уроков и проведённых мероприятий — по REQ-D1–D3.
- **EARS-4** — СИСТЕМА ДОЛЖНА рендерить лидерборд БЕЗ подиума топ-3 над таблицей (развилка podium = вариант А по умолчанию канваса), рыночная таблица — это весь лидерборд.
- **EARS-5** — СИСТЕМА ДОЛЖНА показывать инвестиции и абсолютной суммой в рублях, и долей в процентах (развилка money = вариант А по умолчанию канваса), никогда не только долей.
- **EARS-6** — КОГДА посетитель кликает по любой строке лидерборда, СИСТЕМА ДОЛЖНА независимо от других строк раскрывать/сворачивать две полосы подбаллов этой строки (доля инвестиций в образование, доля внимания врачей), и СИСТЕМА ДОЛЖНА рендерить строку «Ортелла Биотех» уже раскрытой при загрузке страницы, с полосами подбаллов (доля инвестиций в образование 15%, доля внимания врачей 19%), из которых складывается индекс 72.
- **EARS-7** — СИСТЕМА ДОЛЖНА рендерить динамику индекса для топ-3 организаций как 4 недельных столбика с даты запуска индекса (1 сентября 2026), с подписью о запуске как точке отсчёта, и НЕ рендерить ни одного значения до этой даты.
- **EARS-8** — СИСТЕМА ДОЛЖНА рендерить кабинет `/education-index/partner-demo` из того же модуля фикстур: шкала план/факт, 4 плитки KPI (врачей обучено, уроков создано, средняя глубина воронки из 7, мероприятий проведено), блок «осведомлённость до/после» в варианте с двумя полосами (развилка awareness = вариант А по умолчанию канваса) по 4 темам, воронка вовлечения из 7 шагов в точном порядке сериал → микрообучение → вебинар → подкаст → клуб → практическая школа → наставничество, недельная динамика внимания, и блок «Опросы и исследования» с одной уже отправленной заявкой.
- **EARS-9** — СИСТЕМА ДОЛЖНА рендерить таблицу аудитории в кабинете с заголовком, называющим аудиторию проектов и итог 1 240 врачей, ровно 5 строк фикстур промпта 23, и подпись «показано 5 из 1 240 · полный список — в выгрузке для отчётности».
- **EARS-10** — СИСТЕМА ДОЛЖНА рендерить кнопки «Показать ещё» и «Выгрузить для отчётности» в таблице аудитории, а также кнопку «Запросить исследование» в блоке «Опросы и исследования», в отключённом состоянии с подписью «в демо недоступно», и НЕ подключать их ни к каким данным.
- **EARS-11** — СИСТЕМА ДОЛЖНА рендерить закреплённую плашку демо-данных под шапкой на обеих страницах, с формулировкой, специфичной для публичного лидерборда и для кабинета партнёра.
- **EARS-12** — СИСТЕМА ДОЛЖНА рендерить обе страницы корректно в светлой и тёмной теме и на 1440 и 390, по завендоренному канвасу.
- **EARS-13** — СИСТЕМА ДОЛЖНА выдавать директиву robots noindex на обоих маршрутах, потому что это временное демо, которое нельзя индексировать.
- **EARS-14** — КОГДА выходит релиз, поставляющий фичи 032 и 035, СИСТЕМА ДОЛЖНА удалить оба маршрута и модуль фикстур; ни один маршрут `/education-index` не переживает этот релиз.

## Инварианты

- Ни один из маршрутов не делает сетевых запросов после первой загрузки страницы (ни API, ни БД, ни своей телеметрии демо).
- Ни одно запрещённое комплаенсом слово (пациент, спасённая жизнь, помощь родственникам, связь с продажами, торговое название препарата, спонсор, рекламодатель, вкладчик, майнинг) не появляется ни на одной странице.
- Таблица аудитории никогда не показывает больше 5 строк фикстур; кнопка «Показать ещё» никогда не становится активной.
- Доли инвестиций по всем 12 организациям в сумме дают 100%; доли внимания — тоже 100% (инвариант фикстур, из промпта 23).
