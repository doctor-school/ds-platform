# Бриф: Главная страница Академии Doctor School (`/`)

> Вставьте этот бриф новым чатом в дизайн-проект «DS Platform» на claude.ai/design.

## Контекст

Doctor.School — медицинская образовательная платформа: бесплатное образование для врачей, финансируемое фарм-партнёрами. Портал academy.doctor.school уже живёт в продакшене: витрина эфиров, страница эфира, вебинарная комната, «Мои события», профиль. Проектируем **новую главную страницу** — сейчас корень сайта просто перенаправляет на список эфиров.

## Что уже есть в этом проекте — обязательная основа

- `tokens/` + `brand/` — токены и бренд (единственный источник правды по цвету/типографике/отступам).
- `as-is/*.dc.html` — **готовые задизайненные экраны текущего портала**: карточка эфира, витрина эфиров (список + месяц), страница эфира, «Мои события», профиль. Это установленный визуальный язык платформы — главная обязана выглядеть его продолжением, а не отдельным сайтом.
- Карточка эфира и список эфиров — **переиспользуемые юниты**: на главной они те же, что на витрине, менять их дизайн нельзя, только компоновать.

⚠ Стиль: строго существующий язык дизайн-системы из `as-is/` и токенов. Никакого глассморфизма, градиентных свечений и «премиального дарка» из сторонних референсов.

## Аудитория — двойная входная точка

Главная обслуживает два потока сразу и обязана быстро развести их по маршрутам:

1. **Врач** → смотреть контент: лента эфиров, проекты, эксперты → страница эфира → регистрация.
2. **Партнёр (фарма / медбизнес / эксперт)** → понять идею Академии → лид-форма «Обсудить партнёрство».

Врачи и партнёры взаимозависимы: без врачей не интересно партнёрам, без партнёров нет бесплатного образования для врачей. Тон: экспертный, современный, чистый, без инфобизнеса, ощущение влияния и статуса.

## Структура страницы (9 блоков, порядок можно предлагать иначе)

1. **Hero** — что это за проект и для кого; двойной CTA: [Стать партнёром] (якорь на форму) и [Смотреть эфиры] (→ /webinars). Ощущение масштаба и инфраструктурного проекта.
2. **Лента контента** — «Ближайшие и последние эфиры»: переиспользуемый юнит списка эфиров (карточки из `as-is/webinar-card`), 3–6 карточек, переход на страницу эфира, ссылка «Все эфиры».
3. **Что это** — 3–4 карточки: Эксперты / Индустрия / Образование / Партнёры.
4. **Зачем** — противопоставление в 2 колонки: «Сейчас» (устаревающие модели) vs «Мы создаём» (гибкая экспертная среда).
5. **Что мы создаём** — ecosystem map / дорожка: образовательные школы, экспертные сообщества, дискуссионные форматы и подкасты, практико-ориентированные программы, стандарты обучения.
6. **Люди** — «Кто формирует проект»: карточки экспертов (фото, имя, роль, регалии) + медиа-блок «Кто стоит за брендом» (подкаст: ближайшие и прошедшие выпуски). Карточка эксперта — новый переиспользуемый юнит (появятся страницы /experts).
7. **Партнёрам** — 3–4 benefit-карточки: репутация, участие в среде, влияние на рынок, доступ к экспертам.
8. **Форматы участия** — карточки: эксперт, партнёр, участник подкаста, соавтор направления, компания.
9. **Финальный CTA + лид-форма** — поля: имя, компания/клиника, email или Telegram, роль (селект: эксперт / представитель компании / другое); кнопка «Обсудить партнёрство». Состояния: заполнение, ошибки валидации, успех («заявка принята»).

## Тексты

Рыбу пишите сами — осмысленную, по назначению блоков выше (структурный референс — выше, дословных текстов нет намеренно: старые забракованы). Финальные маркетинговые тексты владелец доработает по готовой структуре.

## Что нужно на выходе (Stage A)

**2–3 варианта композиции страницы** — где реально есть развилка: например, (а) hero с лентой эфиров сразу под ним (контент-первый), (б) hero + «что это» сначала, лента ниже (смысл-первый), (в) сплит-hero: контент-колонка врача + партнёрская колонка. Оба брейкпоинта (desktop + mobile), обе темы, интерактивные состояния карточек/формы. Владелец выберет вариант — он станет спекой для разработки.
