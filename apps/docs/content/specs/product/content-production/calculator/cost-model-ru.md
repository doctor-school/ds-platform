# Модель себестоимости единицы

Калькулятор берёт часы и круги из модели (`../model/*.yaml`, `../model/loops.yaml`), состав и мощность команды из `../model/teams.yaml`, ставки ролей из `../rates/rates.yaml`, состав продуктов и переменные из [`products.yaml`](products.yaml) и считает каждую цифру на трёх точках: **min**, **mid** (середина) и **max** каждого диапазона. Сценарий один на все диапазоны сразу: min — минимальные часы, круги, ставки, FTE и драйверы вместе, max — максимальные вместе.

**Рабочая оценка — mid.** min и max — совместные крайние точки всех диапазонов, а не доверительный интервал: все величины одновременно на одной границе на практике не встречаются, поэтому цифры min и max — края, которых ждать не стоит (урок на min и на max отличается примерно в 12 раз). Страница калькулятора показывает ту же подпись.

Считает [`compute.mjs`](compute.mjs) — один модуль для страницы калькулятора и для проверок.

## Себестоимость единицы

**Полная себестоимость единицы = прямые затраты + распределённые накладные + резерв актуализации + внешние затраты, если они заданы** — итог «по загрузке»; итог «с полным фондом оплаты» добавляет неиспользованную мощность штата (раздел ниже).

### Прямые часы и затраты

Часы листа l в продукте: `h(l) × n(l) × q`, где `h(l)` — `hours_draft` листа за проход, `n(l)` — круги петли листа (`effort.iterations`, иначе 1), `q` — количество: произведение количеств по пути «продукт → вложенный продукт → лист» и множителей-драйверов (`per`). Круги петли — `rounds_draft`; у петли с `rounds_from` — `base` + Σ (круги петли из `plus_extra_rounds_of` − 1): сценарий урока на серединах = 1 + (2 − 1) + (2 − 1) = 3.

Прямые затраты = Σ по прямым листам: часы × стоимость часа роли. Каждая строка несёт след «продукт → вложенный продукт → лист → роль → часы × круги × количество → ставка» — его показывает страница калькулятора.

### Какой лист прямой, какой — накладной

Сначала роль, затем единица (решение В8, [`../model/effort-draft-ru.md`](../model/effort-draft-ru.md), «Как это попадает в себестоимость единицы»). Правило — данные в `products.yaml`, раздел `classification`:

| Класс     | Какие листья                                                                                                                                                                          | Куда идут                                       |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Накладные | роль «Ядро…» или «Сервисный круг…» при любой единице; единица периода или системы: команда·месяц, новая команда, деление, найм, ревизия стандартов, СОП, отчётный период, направление | пул накладных периода                           |
| Резерв    | единица «сигнал» или «затронутая единица» (A44–A46)                                                                                                                                   | резерв актуализации единицы                     |
| Прямые    | всё остальное: урок, эпизод, мероприятие, курс, запрос, КП, договор, отчётный этап                                                                                                    | прямые часы той единицы, ради которой выполнены |

Лист «Продуктовая команда» (ретро A56 на договор) — прямой час договора; его ставка — средневзвешенная ставка ролей команды по FTE, в мощности его часы делятся между ролями команды по долям FTE.

### Стоимость часа роли

| Форма                                                                  | Формула                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Штат                                                                   | месячная зарплата gross (min / медиана / max региона) × (1 + взносы) ÷ `paid_hours_per_month`; взносы считаются по году: 30,2 % в пределах предельной базы, 15,1 % + 0,2 % сверх неё                                                                                                                           |
| Подряд, гонорар, аутсорсинг (`engagement` начинается с этих слов)      | `hourly_rub` × (1 + надбавка по форме договора); у диапазона с одной известной границей берётся она с флагом: у пулов экспертов и медрецензентов известна только нижняя граница (от 900 ₽), поэтому флаг говорит прямо — «ставка взята по нижней границе рынка — верхняя и, вероятно, средняя оценка занижены» |
| Круг (`composite_of` без своей ставки)                                 | средневзвешенная ставка ролей круга по FTE того же сценария (на min — FTE min, на max — FTE max); `composite_of` «Продуктовой команды» в `rates.yaml` — те же роли команды направления, между которыми делятся её часы в мощности (проверяет `trace-check.mjs`)                                                |
| Прокси (`rate_proxy` в `products.yaml`, по `proxy_role` записи ставок) | ставка прокси-роли: «Медиа-круг — голос» — монтажёр                                                                                                                                                                                                                                                            |

Роль, у которой нет ни одной формы, — «ставка не задана»: её строка не входит в итог, и итог несёт флаг. Регион — переменная `region` (по умолчанию Москва); роль без медианы региона берёт Москву с флагом. Доля пиковых часов медиа-круга во внешнем пуле — `media_external_share` (по умолчанию 0): стоимость часа подроли = (1 − доля) × штат + доля × подряд. Сдельная цена из `per_piece` подставляется правкой `piece:<лист>` — рубли за проход листа вместо часы × ставка; как в `rates.yaml` `formulas.per_piece_cost`, к ней прибавляется надбавка подрядчика по форме договора.

### Пул накладных и его распределение

План периода — один месяц. По умолчанию `teams` команд направления (1) работают на полную мощность над продуктом `plan_mix` (курс): курсов в месяц = мощность команды на курс; отсюда уроки, эпизоды, клубы и сделки месяца. Правка `plan:<продукт>` задаёт план явно.

Пул накладных за месяц = накладные листья единиц плана (юрист A3132 — только на долю спонсорских и брендированных уроков, параметр урока `доля_спонсорских`; публикация A42, сервисный круг мероприятий A333–A336, юрист A16 и бухгалтер A53 сделки) + листья периода из `period_leaves` × число их проходов в месяц (governance A641, коучинг A642, база экспертов A643, метрики A653 — на команду·месяц; выход на рынок A11; выплаты A54 и калибровка A654 — на отчётный период; открытие A61, деление A62, найм A63, ревизия стандартов A651, СОП A652 — по числу событий). Стоимость — часы × ставка роли.

**Накладные на единицу = прямые часы единицы × (пул за месяц ÷ прямые часы плана за месяц).** Непроизводственное время команд в базу не входит — база содержит только прямые часы. Продукт вне плана (конгресс при плане «курс») получает ту же ставку на прямой час; его собственные накладные часы показываются отдельно (`overhead.ownHours`), но в пул попадают, только когда он стоит в плане.

### Неиспользованная мощность штата

Штатная роль команды оплачивается за все `FTE × P` часов в месяц, а единицы плана загружают её не полностью: на полную мощность работает только узкое место (медредактор-сценарист), у остальных ролей остаются оплаченные свободные часы. Для каждой роли команды со штатной ставкой:

`свободные часы(r) = команд × FTE(r) × P − N(r) − L(r)`, где `N(r)` — непроизводственные часы (листья периода, они уже в пуле), `L(r)` — часы роли во всех листьях единиц плана (часы «Продуктовой команды» делятся по FTE). Стоимость — свободные часы × стоимость часа роли. Если план требует больше часов, чем есть, свободных часов 0 и итог несёт флаг «перегрузка штата».

Решение владельца (2026-10-05, эпик #2522, «Idle paid time»): калькулятор показывает **обе** цифры, выбор для предложения делается при расчёте КП.

| Итог                     | Что входит                                                                                                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «по загрузке»            | прямые + накладные + резерв (+ заданные внешние); свободные часы и их рубли показаны отдельно как сигнал периода по ролям и в себестоимость не входят       |
| «с полным фондом оплаты» | то же + строка следа «неиспользованная мощность штата»: стоимость свободных часов команд плана, распределённая на единицы ∝ прямым часам, как пул накладных |

Сверка: за месяц плана Σ (прямые + накладные + неиспользованная мощность) по всем единицам плана = фонд оплаты штатных ролей команд плана (с взносами) + прямые затраты и пул по остальным ролям (подряд, пулы, круги, ядро). Итог «по загрузке» меньше ровно на стоимость свободных часов. Резерв актуализации и внешние затраты — сверх сверки: резерв — работа будущих периодов срока договора. В итоге «с полным фондом оплаты» резерв частично совпадает со свободными часами: актуализацию будет делать та же штатная команда, чьё незанятое время уже оплачено. Это около 2 % итога на mid (от 0,7 % на min до 4,4 % на max).

При `media_external_share` > 0 загруженные часы подроли медиа-круга, учтённые по смешанной ставке, делятся так: доля внешнего пула оплачивается подрядчику за каждый загруженный час, остальное — штатное время. Непроизводственные часы (встречи, найм, управление — листья периода) — всегда штатное время: пул накладных считает их по штатной ставке, в том числе часы круга «Продуктовая команда». Свободные часы и фонд оплаты считаются только по штатной части и по штатной ставке: подрядчику за простой не платят.

### Резерв актуализации (В6)

Для единицы с линией (`reserve_line`: урок — A31, эпизод — A32):

`резерв = сигналы на единицу × A44 + доля затронутых × (A45 + A46 + доля пересборки × прямые часы линии единицы)` — в часах и в рублях по ставкам ролей. Переменные `signals_per_unit`, `affected_share`, `rebuild_share` — в `products.yaml`. Резерв модуля, курса, специальности — сумма резервов их уроков и эпизодов.

### Внешние затраты

ИИ-генерация, голоса и лицензии, студия подкаста, гонорар спикера подкаста, площадка и трансляция, гонорары спикеров и амбассадора мероприятия названы в модели, но значений нет. В `products.yaml` у них `rub: null`: калькулятор показывает строку «не задано», не считает её нулём, исключает из итога и ставит флаг «внешние затраты не заданы: …» с названиями незаданных затрат. Значение задаёт правка `external:<id>` — рубли на единицу `per`.

## Мощность и срок

Те же формулы, что в [`../model/capacity-ru.md`](../model/capacity-ru.md): доступные часы роли команды `A(r) = FTE(r) × P − N(r)` (N — листья периода роли и её доля по FTE листьев «Продуктовая команда»), мощность `C(U) = min A(r) ÷ H(r, U)`, узкое место — роль минимума; обязательство пулов `K(r) = C × H(r)`. Нужные FTE на ритм: `единиц в неделю × 52/12 × H ÷ (P − N(r)/FTE(r))`. Срок листа `D(l) = d(l) × n(l) + (n(l) − 1) × w(l)`, цепочка — сумма, параллельные ветви — максимум (`lead.chain` продукта). Модуль, курс, специальность — конвейер: срок первых единиц + (число уроков − 1) × такт, такт = рабочие дни в месяце ÷ мощность на урок; клубы и эпизоды — параллельно.

## Калибровка

Правки — плоская карта «ключ → значение» поверх YAML; YAML не меняется. Страница калькулятора хранит и выгружает её, владелец переносит принятые значения в YAML.

| Ключ                                  | Что меняет                                                                 |
| ------------------------------------- | -------------------------------------------------------------------------- |
| `leaf:<лист>` / `lead:<лист>`         | часы за проход / срок прохода листа (число или `[min, max]`)               |
| `loop:<петля>` / `wait:<петля>`       | круги петли (заменяет и `rounds_from`) / ожидание между кругами            |
| `rate:<роль>:monthly`                 | месячная зарплата роли в текущем регионе (число или `[min, медиана, max]`) |
| `rate:<роль>:hourly` / `:hourly_cost` | час подрядчика / итоговая стоимость часа роли                              |
| `piece:<лист>`                        | сдельная цена за проход листа вместо часы × ставка                         |
| `fte:<роль>`                          | FTE роли в команде направления (роль из `teams.yaml` или `rates.yaml`)     |
| `var:<имя>`                           | переменная `teams.yaml`, `products.yaml` или ставка взносов                |
| `param:<продукт>:<параметр>`          | параметр продукта (сделки, этапы, секции …)                                |
| `external:<id>`                       | внешняя затрата на единицу                                                 |
| `plan:<продукт>`                      | явный план единиц в месяц вместо команды на полной мощности                |

Неизвестный ключ — ошибка: правка не может молча пропасть.
