# Управленческий слой калькулятора — заметки к макету

Макет: [`mockup-management.html`](mockup-management.html) (раздать папку `content-production` по HTTP и открыть `/calculator/mockup-management.html`). Расчёт — [`mockup-management.mjs`](mockup-management.mjs) поверх [`compute.mjs`](compute.mjs) на текущих YAML; формулы модели — [`cost-model-ru.md`](cost-model-ru.md).

## Формулы

Сценарий s; часы ролей, круги и ставки модели при s — ключ распределения, только чтение.

1. **Коэффициент пула** `k(g) = ввод(g) ÷ оценка(g)` для пула g ∈ {ФОТ, медиа-круг, эксперты, рецензенты, накладные}. Стоимость часа роли r пула g = ставка модели(r) × `k(g)`: структура (кто сколько часов и почём относительно других) — из модели, уровень денег — ввод.
2. **Прямые единицы** = Σ по операциям единицы: часы × круги × количество × ставка модели(роль) × `k(пул роли)`.
3. **Накладные единицы** = прямые часы единицы × ставка на прямой час; ставка = (`k(накладные)` × оценка накладных + `k(ФОТ)` × непроизводственное время штата) ÷ прямые часы плана месяца.
4. **Резерв актуализации** — формула `cost-model-ru.md` (В6), рубли по ролям × `k(пул роли)`. **Внешние** = количество × ввод ₽ на единицу; «не задано» — не входит в итог и не считается нулём.
5. **Себестоимость по загрузке** = прямые + накладные + резерв + заданные внешние. **С полным ФОТ** = по загрузке + прямые часы × (`k(ФОТ)` × стоимость свободных часов штата ÷ прямые часы плана). **Маржа** = цена − себестоимость выбранной базы; **маржа %** = маржа ÷ цена.

**Сверка месяца:** Σ по плану (прямые + накладные + простой) = ФОТ + медиа-круг + эксперты + рецензенты + накладные — на каждом сценарии, при любых вводах (макет показывает расхождение 0 ₽). Резерв и внешние — сверх сверки, как в `cost-model-ru.md`.

ФОТ — одна сумма, а не по ролям: её раскладывает структура ФОТ из модели (доля роли = FTE × ставка). Перекос внутри команды (подняли зарплату одной роли) одной суммой не выражается — это вопрос владельцу ниже.

## Непрерывность с текущим калькулятором

При всех вводах «оценка по модели» `k = 1` везде, и цифры макета равны текущему калькулятору до рубля (макет сравнивает живьём):

| Продукт | По загрузке min / mid / max        | С полным ФОТ min / mid / max       |
| ------- | ---------------------------------- | ---------------------------------- |
| Урок    | 57 821 / 243 609 / 704 660         | 94 645 / 416 750 / 1 177 467       |
| Курс    | 1 228 067 / 4 980 657 / 14 168 946 | 2 005 756 / 8 502 136 / 23 634 659 |
| Сделка  | 17 111 / 82 622 / 258 138          | 24 522 / 123 388 / 375 826         |

Урок на mid по загрузке — 243 609 ₽, как в текущем калькуляторе: расхождения нет. Внешние затраты урока и курса не заданы и в эти цифры не входят.

## Что уходит из вводов в модель (только чтение)

- Часы и сроки 63 операций, круги согласования — ключ распределения и разбор; меняются редко, через PR в модель.
- 33 ставки ролей — задают только структуру внутри пула; уровень денег — месячная сумма пула.
- FTE ролей — структура ФОТ; сумма ФОТ — ввод.
- Переменные периода (выходы на рынок, отчётные периоды, новые команды, деления, найм, ревизии стандартов, СОП) — внутри оценки накладных; сумма накладных — ввод.
- Драйверы резерва актуализации и параметры продуктов (сделок на курс, этапов, секций, дней).

Разбор остаётся: продукт → функция схемы IDEF0 (A3 → A31 → A313) → операция → роль, часы из модели, рубли по управленческим суммам; ниже — накладные, резерв, внешние, простой.

## Вопросы владельцу

1. ФОТ одной суммой или по группам ролей (например, «продажи — аккаунт» отдельно от «производства»)? Одна сумма не выражает перекос зарплат внутри команды.
2. Пулы и накладные — месячная сумма (как в макете) или ставка за час / за единицу? Сейчас сумма следует за планом, пока не вписана; вписанная — фиксируется, и при росте плана час пула дешевеет.
3. Резерв актуализации — оставить за моделью (как в макете) или вынести вводом «% к прямым»?
4. Простой при одной команде большой (mid: 837 302 ₽ из 1 482 653 ₽ ФОТ — загружен на 100 % только медредактор-сценарист). Это сигнал к составу команды или ожидаемая картина первого года?
