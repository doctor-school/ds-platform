# Глоссарий реестра производства контента DS

Один термин — одна запись. Определения нейтральны к модели (не называют людей, R2). Колонка «EN slug» — для последующего переноса в глоссарий репозитория (`apps/docs/content/product/glossary/`). Источники: черновик владельца «Процесс разработки образовательного контента» (2026-09-30) — черновик владельца, `Ln` — транскрипт 2026-09-30, `M:` — встречи BBM, `P` — legacy BPMN мероприятий, `ВЛ` — ответы владельца 2026-10-01 и 2026-10-05, `AS` — механика авторской доли BBM finmodel (bbm decisions-log 2026-08-10).
