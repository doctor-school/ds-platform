# Мощность команды и срок единицы — формулы

**Это формулы и переменные, не расчёт.** Числа ниже — пример на серединах черновых диапазонов, чтобы показать ход вычисления; считает и калибрует калькулятор (#2527). Денег здесь нет.

Источники переменных:

| Переменная                                          | Где лежит                                                                                                                                                             |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `h(r, U)` — часы роли r на единицу U за проход      | `effort.hours_draft` листьев (`A*.yaml`), сводка — [`effort-draft-ru.md`](effort-draft-ru.md)                                                                         |
| `d(l)` — срок прохода листа l, рабочие дни          | `effort.lead_days_draft` листьев                                                                                                                                      |
| `n(l)` — круги листа l                              | `rounds_draft` петли из [`loops.yaml`](loops.yaml), имя — `effort.iterations`; у петли с `rounds_from` — 1 + Σ (круги названных петель − 1); лист без петли — 1       |
| `w(l)` — ожидание между кругами                     | `wait_days_per_round_draft` той же петли                                                                                                                              |
| `FTE(r)`, `P` — состав и оплачиваемые часы на 1 FTE | [`teams.yaml`](teams.yaml): `members`, `draws_on`, `paid_hours_per_month` (тот же делитель берёт стоимость часа штата в [`../rates/rates.yaml`](../rates/rates.yaml)) |
| `N(r)` — непроизводственные часы роли в месяц       | листья модели с единицей периода или события: `команда·месяц` (A641, A643), деление A62, найм A63, СОП A652, ретро A56                                                |
| `K(r)` — обязательство пула на период               | `draws_on[].commitment` в `teams.yaml` (медиа-круг, эксперты, рецензенты)                                                                                             |

## Мощность команды на единицу U в месяц

Прямые часы роли на единицу с учётом кругов: `H(r, U) = Σ по листам l единицы U с ролью r: h(l) × n(l)`.

Непроизводственные часы роли в месяц `N(r)` — не доля и не коэффициент, а листья модели: собственные листья роли с единицей `команда·месяц` (A643 у менеджера эксперта) плюс её доля листьев «Продуктовая команда» (часы листа суммарны по участникам — доля роли = часы × FTE(r) ÷ FTE команды): governance A641 каждый месяц, а деление A62, найм A63, СОП A652 и ретро договора A56 — по числу таких событий в плане периода. Доступные часы роли в месяц: для роли команды `A(r) = FTE(r) × P − N(r)`; для общего пула — обязательство на период `A(r) = K(r)` (В3: медиа-круг фиксирует часы по подролям; эксперты и рецензенты резервируются на курс).

Мощность команды, если она делает только единицу U:

`C(U) = min по ролям r: A(r) ÷ H(r, U)`, узкое место — роль, на которой достигается минимум.

Смесь единиц (план периода `N(U)` уроков, эпизодов, мероприятий) — нагрузка роли `L(r) = Σ по U: N(U) × H(r, U)`, загрузка `L(r) ÷ A(r)`; план выполним, если загрузка каждой роли ≤ 1, узкое место — роль с наибольшей загрузкой. Обязательство пула на период выводится обратно: `K(r) = L(r)`.

Роли сервисного круга и ядра в мощность команды не входят: это накладные (В8), их мощность считается на все команды сразу — та же формула с суммой планов всех команд.

## Срок единицы

Срок прохода листа с петлёй: `D(l) = d(l) × n(l) + (n(l) − 1) × w(l)`. `d(l)` уже включает ожидание внешней стороны внутри прохода (ответ эксперта, решение фармы), `w(l)` — только разрыв между кругами, поэтому ничто не считается дважды.

Срок единицы — сумма `D(l)` по цепочке листов в порядке стрелок диаграмм; параллельные ветви дают максимум, а не сумму. Цепочки по стрелкам:

| Единица           | Цепочка (стрелки диаграмм)                                                                                                                                                                                                             |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Урок (A31)        | A3111 → A3112 → A3113 (A311) → A312 → A3131 → A3132 → A3133 → A3134 (A313) → [ A3141 → max(A3142 → A3144; A3143; A3145) → A3146 (A314) ∥ A315 ] → A3161 → A3162 → A3163 (A316); выпуск — A41 → A42, анонс A43 идёт за неделю до релиза |
| Эпизод (A32)      | A321 → A322 → A323 → A324 → A325                                                                                                                                                                                                       |
| Мероприятие (A33) | A331 → A332 → A333 → max(A334; A335) → A336                                                                                                                                                                                            |
| Курс (A2)         | A21 → A22 → max(A23 → A24; A25) → A26 (A25 ветвится от A22 параллельно A23), затем уроки, эпизоды и клубы курса                                                                                                                        |

Петли замечаний (A31 `a03` — сценарий на доработку, `a07` — правки монтажа) в цепочке не рисуются отдельно: они уже в `n(l)` листов, которые повторяются.

Перевод в месяцы — `working_days_per_month` из `teams.yaml`. Незавершённая работа по закону Литтла: `WIP = (C(U) ÷ дни в месяце) × срок единицы` — столько единиц одновременно в работе у команды при полной загрузке.

## Как считаются остальные единицы

- **Модуль** = 6 уроков + клуб (мероприятие A33). Часы роли: `H(r, модуль) = 6 × H(r, урок) + H(r, мероприятие)`; мощность — та же формула. Срок модуля = срок первого урока + 5 × такт + клуб параллельно, где такт = дни в месяце ÷ `C(урок)` (≈ 4,7 дня в примере) — уроки идут конвейером через узкое место.
- **Курс** = проектирование A2 (часы на курс; срок цепочки A2 ≈ 61 рабочий день на серединах) + 3 модуля + 18 эпизодов подкаста. Срок курса = срок A2 + срок первого урока + 17 × такт; эпизоды и клубы — параллельные линии со своими ролями, узким местом становятся, только если их загрузка выше.
- **Эпизод подкаста** (A32): часы на эпизод — менеджер эксперта 4,5, медредактор 3, запись 2,5, монтажёр 4,5 (середины с кругами); срок ≈ 19 рабочих дней.
- **Вебинар** (A33): прямые часы команды — менеджер мероприятий 6, менеджер эксперта 4; часы сервисного круга (оператор, режиссёр, поддержка) — накладные; срок ≈ 34,5 рабочих дня от подготовки до отчёта.
- **Направление** = Σ единиц плана + постоянная часть команды·месяц (A64, A653) — нагрузка ролей через ту же смесь `L(r)`.

Резерв актуализации единицы (В6) добавляет к нагрузке роли сигналы × часы A44–A46 по правилу [`effort-draft-ru.md`](effort-draft-ru.md).
