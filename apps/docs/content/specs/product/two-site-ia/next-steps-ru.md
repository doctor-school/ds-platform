## 4. Чеклист 4 рисков (Cagan) — статус

- **Value (врач)**: **проверено опытом действующего бизнеса** — первичные бизнес-требования собраны на многолетнем опыте работы с ЦА и на данных действующего продукта Doctor.School (~10k врачей в базе, действующие партнёры, работающая школа OrthoBioSchool). Это **реструктуризация действующего бизнеса, а не стартап-проект**, поэтому статус «валидированная постановка» сохраняется, а свежие интервью с врачами **не являются блокером ставки** (позиция владельца; замечания V-RV-2 и C-RV-16 сняты с обоснованием). _Опционально, не блокер:_ разговоры для калибровки конкретных гипотез — 2–3 врача ядра ЦА (REQ-32), медпред партнёра (REQ-14), эксперт-автор (REQ-27/42), комплаенс-офицер первого партнёра (CON-10/11).
- **Value (партнёр)**: сильнее — рыночная норма списков (REQ-18), опросы (REQ-10); проверяется первым контрактом (REQ-87).
- **Usability**: throwaway-wireframe + живой прототип приложения (REQ-53).
- **Feasibility**: «внутрянка» на старте ручная (NG-3, CON-3); ключевые сквозные срезы — врач по партнёрской ссылке → урок → внимание → отчёт партнёру; проект → конгресс в конструкторе → билет одной кнопкой (к ноябрю).
- **Viability**: смарт-контракт-экономика (REQ-59/87/90) — финмодель BBM. **[R2]** Открыто: кто несёт риск **недобора** внимания (Q-37) и какой числовой порог доказывает ставку (Q-39).

## 6a. Порядок дальнейших шагов — решение владельца 2026-08-19 (после [R2])

3. **Согласование макета с командой** → правки макета по замечаниям (итерации на макете, не в документах).
4. Только затем — **Commit** (ADR/модель данных, §7) и **Build** (EARS в `ds-platform`).

## 7. Материал для Commit-полосы (когда владелец даст ход)

- ADR на принятые OWD-1…10 (в репо `ds-platform`, по его конвенциям); OWD-11 и OWD-12 — только после решения на betting table.
- Модель данных ядра из реестра: человек/учётка (роли-атрибуты), эксперт (без учётки, связывание — REQ-98/Q-27), организация-инвестор, проект (сквозной ID), школа/курс/урок, событие (конструктор), клиническая база, специальность, очки внимания/начисления, НМО-реестр.
