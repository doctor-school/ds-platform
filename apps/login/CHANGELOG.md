# @ds/login

## 0.2.0

### Minor Changes

- [#3510](https://github.com/doctor-school/ds-platform/pull/3510) [`9e32b66`](https://github.com/doctor-school/ds-platform/commit/9e32b66fb30afe88e56afb74b3a5cdbf37e2f57d) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - A refused sign-in entry (too many attempts from one address, or the service not answering) now opens a refusal page instead of a bare server error on the storefronts and a lone error banner on the sign-in site: a light-hearted heading and text, a retry button that counts down the wait when the service names one, and a way back to the эфир, the home page or the two storefronts (003 EARS-72).

  Breaking for `@ds/auth-flow`: `storefrontEntry` returns a typed refusal (`{ refused }`) instead of throwing, the storefront doors are answered by `storefrontDoorGate` from each storefront's gate, and `SIGN_IN_HOST_UNAVAILABLE_HEADER` / `readSignInHostUnavailable` / `SignInHostUnavailable` are replaced by `ENTRY_REFUSAL_HEADER` / `readEntryRefusal` / `EntryRefusal`.

### Patch Changes

- [#3228](https://github.com/doctor-school/ds-platform/pull/3228) [`ede12bc`](https://github.com/doctor-school/ds-platform/commit/ede12bc93eeee678552e81aff9e11ccd818ad9dd) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - A dark or light theme the visitor chose on either storefront now carries over to the sign-in page, which renders it from the first paint.

- [#3265](https://github.com/doctor-school/ds-platform/pull/3265) [`d8ab3cf`](https://github.com/doctor-school/ds-platform/commit/d8ab3cfd6532eec4e41db63a5953a4d114c50d82) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - «Войти», registration and password reset on both storefronts now run on the shared sign-in page, and the person comes back signed in on the page they started from. Signing out on a storefront also ends the shared sign-in, so the next «Войти» asks for the password again.
