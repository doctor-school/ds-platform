# @ds/e2e

## 0.2.0

### Minor Changes

- [#3696](https://github.com/doctor-school/ds-platform/pull/3696) [`75cd103`](https://github.com/doctor-school/ds-platform/commit/75cd103965f30efdb845bff8e26a01517c9aabf3) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - Entry into the specialty feed (018 entry, 017 EARS-1 / EARS-6 / EARS-7, 021 LD-4, [#3674](https://github.com/doctor-school/ds-platform/issues/3674)): a direct arrival with a remembered specialty lands on that specialty's feed `/feed/<code>` (the doctor host's `landing.specialtyFeed` is now the route template `/feed/:code`), and the home when nothing is chosen. Choosing a specialty in the home catalog opens its feed. The doctor header gains «Моя лента» → `/feed`, a server redirect to the remembered specialty's feed, or to the home specialty catalog (`/#specialties`) when none is chosen. `@ds/e2e`'s navigation model lets an item declare the pages its href redirects to (`landing.redirectsTo`), and the derived walk accepts only those, each with its own evidence (`landingEvidenceAt`, replacing `landingEvidence`).

### Patch Changes

- [#2639](https://github.com/doctor-school/ds-platform/pull/2639) [`7a13a8a`](https://github.com/doctor-school/ds-platform/commit/7a13a8a82f723ee0f84f5709a7d3dcd91499530e) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - Golden seed: the named эфиры are Academy (`experts`) events of kind «Эфир», so the Academy listing and archive carry the cards the 004/014 stage scenarios open; `golden-event-live` stays the doctor storefront's `doctors` room and a new `golden-event-live-academy` is the Academy's, each with a named registrant. The 003 logout scenario expects the storefront home after sign-out.

- [#3709](https://github.com/doctor-school/ds-platform/pull/3709) [`f509761`](https://github.com/doctor-school/ds-platform/commit/f509761c720e501f312b880c2076254fe8265833) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - [#3705](https://github.com/doctor-school/ds-platform/issues/3705): the golden seed carries one published Academy news item (`golden.materials.published`, slug `golden-material-published`) and its feed card, so the stage route walk resolves the 048 reading page `/materials/[slug]` instead of failing on a missing route-params entry. A re-run keeps the material's first publication instant and the card date together.

- [#2606](https://github.com/doctor-school/ds-platform/pull/2606) [`ac3c945`](https://github.com/doctor-school/ds-platform/commit/ac3c9452087aa2a12c1fdd5f4932bb3ce3c454e8) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - A non-production stand can accept a secret bot-protection test token
  (`BOT_PROTECTION_TEST_TOKEN`) in place of the Yandex SmartCaptcha validation,
  with a distinct `test-token` result reason (not written to the audit ledger); the api refuses to boot with it unless
  `SENTRY_ENVIRONMENT` is `stage`, `development` or `test` ([#2605](https://github.com/doctor-school/ds-platform/issues/2605)). `@ds/e2e`
  exports `installCaptchaStub` (`@ds/e2e/captcha-stub`) to resolve the widget
  with that token in browser drives. Production behaviour is unchanged.
