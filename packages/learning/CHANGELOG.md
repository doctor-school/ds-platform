### Minor Changes

- [#4313](https://github.com/doctor-school/ds-platform/pull/4313) [`4349d38`](https://github.com/doctor-school/ds-platform/commit/4349d38b8190ef7f5807fc2c90779570549a1886) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - 023 EARS-1 / EARS-2 / EARS-27 / EARS-28 ([#4282](https://github.com/doctor-school/ds-platform/issues/4282)): a module's club and the module reward. `PATCH /v1/admin/learning/modules/{id}` takes `clubEventId` (a live 020 event, `null` turns the club off; an unknown or removed event is refused naming the field) and the admin module read carries `clubEventId` with the event's title and start. The 024 rule setting `module.reward` (`points` | `document` | `both`, platform default `points`) is set at the course and the module layers through the existing rules endpoints; on a published course its change takes `learning_rules_editor`. Migration 0079 adds `learning_modules.club_event_id` and the platform seed value. In the admin the course editor picks, shows (title and Moscow start), changes and clears each module's club through the events picker, and the rules editor offers «Награда за модуль» as a choice («Баллы», «Документ», «Баллы и документ») at the course and module scopes.

- [#4278](https://github.com/doctor-school/ds-platform/pull/4278) [`40352e8`](https://github.com/doctor-school/ds-platform/commit/40352e8b68517e820c010f3e986af0039470cb06) Thanks [@sidorovanthon](https://github.com/sidorovanthon)! - 023 EARS-26 / EARS-27 / EARS-28 ([#4018](https://github.com/doctor-school/ds-platform/issues/4018)): the school → course → module structure editor. Staff create a school by direction, leading expert and project, edit its data (facts up to four, «скоро», community, mentoring and internship offers), publish or unpublish it and order its courses; in a course they edit its data and partner, rename and order its modules and publish it once it holds a published lesson. New admin endpoints under the existing envelope: `PATCH /v1/admin/learning/schools/{id}`, `POST …/schools/{id}/publish|unpublish`, `PUT …/schools/{id}/course-order`, `PATCH …/courses/{id}`, `PUT …/courses/{id}/module-order`, `PATCH …/modules/{id}`.

  A school republished while it already has a published course sends its pending «first course open» notices once (023 EARS-7).
