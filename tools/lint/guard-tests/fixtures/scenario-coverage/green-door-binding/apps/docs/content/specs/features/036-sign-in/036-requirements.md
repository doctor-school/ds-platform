# 036 — Sign-in doors (fixture)

## Handlers

- **EARS-1** WHEN a guest signs in, THE SYSTEM SHALL open a session.
- **EARS-2** WHEN a guest registers, THE SYSTEM SHALL send a code.
- **EARS-3** WHEN a guest confirms the code, THE SYSTEM SHALL sign the guest in.
